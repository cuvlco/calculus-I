# Πότε μια συνάρτηση 𝑓 : 𝐴 → ℝ λέγεται συνάρτηση 1-1;
Μια συνάρτηση 𝑓 : 𝐴 → ℝ λέγεται συνάρτηση 1−1, όταν για οποιαδήποτε 𝑥1,𝑥2 ∈𝐴 ισχύει η συνεπαγωγή:

αν 𝑥1 ≠ 𝑥2, τότε 𝑓⁡(𝑥1) ≠ 𝑓⁡(𝑥2).

Με απαγωγή σε άτοπο αποδεικνύεται ότι:

Μια συνάρτηση 𝑓 : 𝐴 → ℝ είναι συνάρτηση 1−1, αν και μόνο αν για οποιαδήποτε 𝑥1,𝑥2 ∈𝐴 ισχύει η συνεπαγωγή:

αν 𝑓⁡(𝑥1) = 𝑓⁡(𝑥2), τότε 𝑥1 = 𝑥2.
# Κρυφό Θεώρημα
Αν μια συνάρτηση είναι γωησίως μονότονη, τότε προφανώς, είναι συνάρτηση 1-1

(i) Αν η συνάρτηση 𝑓 : 𝐴 → ℝ είναι 1−1 τότε η 𝑓 έχει αντίστροφη συνάρτηση.

g : f(A) → ℝ
 
 με την οποία κάθε y ϵ f(A) αντιστοιχίζεται στο μοναδικό x ϵ A για το οποίο ισχύει f(x) = y.
